# Coffee Reviews Sentiment Analysis

## Project Overview
This project analyzes customer reviews for a fictional coffee shop using Python in Google Colab. It explores customer feedback, identifies positive and negative language, classifies review sentiment, and generates warm, professional business replies.

## Objectives
- Analyze a sample of 10 customer reviews.
- Identify positive and negative keywords.
- Classify reviews into Positive, Negative, and Mixed/Neutral categories.
- Explore sentiment counts and percentages.
- Generate unique, customer-focused business replies.
- Export the results to a CSV file for further review.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- CSV data processing
- Rule-based sentiment analysis
- LLM-assisted response-writing concepts

## Project Files
- **Coffee Review Sentiment Analysis.ipynb** — notebook containing the code, analysis, and outputs.
- **Coffee Reviews with Replies.csv** — analyzed reviews with sentiment labels and generated business replies.

## Key Learning Outcomes
- Working with text data in Python.
- Cleaning and matching keywords while accounting for punctuation.
- Creating and analyzing a Pandas DataFrame.
- Summarizing sentiment results and visualizing data.
- Generating customer-service replies with a defined tone and constraints.
- Exporting analysis results and publishing a project on GitHub.

## Important Note
This is a small educational demonstration. Sentiment classification is based on predefined keywords and may not capture context, sarcasm, or complex emotions accurately. Business replies are generated drafts and any proposed actions should be verified before being communicated to customers.

## How to Run
Open the notebook in Google Colab and run the cells in order. The sample reviews are included in the notebook.
